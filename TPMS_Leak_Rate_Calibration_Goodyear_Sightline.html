1. Purpose & Scope

This document defines the standard procedure used by the Goodyear Sightline Vehicle Validation Team to calibrate TPMS (Tyre Pressure Monitoring System) leak rate detection intervals whenever a vehicle's tyre size or recommended inflation pressure changes. The method is tire-size-independent — it uses a direct 60-second pressure measurement on the actual mounted tyre to derive the correct ECU interval values without relying on geometric approximations.

ℹ️
Scope Applicable to all passenger vehicle programmes validated under the Sightline platform where TPMS detection intervals are stored as calibratable ECU parameters (leak rate → interval lookup tables).

1.1 Applicability

  • Any tyre size change on an existing validated platform
  • Cross-vehicle carry-over of TPMS calibration data
  • New tyre fitments (OEM or OE-equivalent) on a validated vehicle
  • Inflation pressure changes due to load rating or regional requirements

2. Background — Why Intervals Change With Tyre Size

2.1 How the TPMS Leak Detection Works

The TPMS ECU continuously monitors pressure. For each Leak Rate category, an Interval defines the time window over which a minimum pressure drop must be observed. If the measured drop exceeds the threshold within that window, a leak alert is triggered.

ΔPthreshold = Leak Rate × Interval
A fixed pressure-drop threshold is expected to be detected within the interval for each leak rate category

2.2 Why Tyre Volume & Pressure Affect the Interval

For an identical physical leak (same orifice/nail size), the rate of pressure drop depends on the air volume inside the tyre and the inflation pressure:

dP/dt ∝ P / V
Larger tyre volume (V) → slower pressure drop · Higher inflation pressure (P) → faster pressure drop

Therefore the detection interval scales as:

Intervalnew = Intervalold × (Vnew / Vold) × (Pold / Pnew)
Where P is absolute pressure (gauge + 101.3 kPa atmospheric)
Volume Effect
Smaller tyre volume → same leak removes proportionally more air per second → pressure drops faster → shorter interval needed.
Pressure Effect
Lower inflation pressure → less driving force pushing air out → mass flow is slower → pressure drops slower → longer interval needed.
⚠️
Important In practice, these two effects can partially cancel. Always use the empirical method (Section 4) on the actual mounted tyre rather than relying solely on theoretical calculations — real-world tyre volumes deviate from idealised torus geometry by ±5%.

3. Equipment & Pre-Conditions

Required Equipment

  • Calibrated digital tyre pressure gauge (±0.1 PSI / ±0.5 kPa accuracy)
  • ECU diagnostic tool with live pressure data logging (≥ 10 Hz sample rate)
  • Controlled orifice reference plug — 1.5 mm diameter (standard Sightline reference leak)
  • Timer / stopwatch (±0.5 s accuracy)
  • Reference calibration sheet (this document)

Pre-Conditions

  • Vehicle at rest ≥ 2 hours (cold tyre condition)
  • Ambient temperature: 15 °C – 35 °C
  • Tyre inflated to manufacturer recommended pressure (door placard)
  • ECU loaded with reference (old) calibration — do not pre-load new values
  • Stable indoor or wind-sheltered environment
🚫
Do Not Run On Public Roads All leak calibration tests must be conducted in a controlled workshop or test bay with the vehicle stationary. Never create an intentional tyre leak on a moving vehicle.

4. Calibration Procedure

INFLATE target tyre to recommended pressure (cold)
↓
Load REFERENCE ECU calibration (original tyre intervals)
↓
Insert 1.5 mm reference orifice → Run for exactly 60 SECONDS
↓
Record pressure loss (kPa) → Calculate Leak Rate = P_loss × 1440
↓
Compute Multiplier = Discovered Leak Rate ÷ Desired Leak Rate
↓
New Interval = Old Interval × Multiplier — for ALL 8 setpoints
↓
✔ Flash new calibration to ECU · Validate at each setpoint

4.1 Step-by-Step Instructions

1
Prepare the Tyre

Inflate the target tyre to the vehicle manufacturer's recommended cold inflation pressure (from door placard). Record the pressure as P₀. Allow 15 minutes for pressure to stabilise.

2
Load Reference Calibration

Using the diagnostic tool, confirm the ECU contains the original / reference leak rate interval map. Do not modify any values at this stage.

3
Insert Reference Orifice & Start Timer

Insert the 1.5 mm standard orifice plug into the tyre valve stem (or a dedicated test port). Start the 60-second timer simultaneously.

  • Maintain consistent ambient temperature throughout the test
  • Do not disturb the tyre during the 60-second window
4
Record Pressure Drop

At exactly 60 seconds, remove the orifice and immediately read the tyre pressure (P₁).

P_loss (kPa) = P₀ − P₁
5
Calculate Discovered Leak Rate

Convert the measured pressure loss to the system's leak rate unit using the standard Sightline formula:

Leak Ratediscovered = P_loss (kPa) × 1440
1440 = minutes per day (24 h × 60 min) — normalises to system daily-rate units
6
Compute the Scale Multiplier

For each target leak rate setpoint (e.g. 30,000), calculate the multiplier:

Multiplier = Leak Ratediscovered ÷ Leak Ratedesired
7
Calculate New Intervals

Apply the multiplier to every setpoint in the reference interval table:

Intervalnew = Intervalold × Multiplier
Round to nearest 5 ms per ECU timer resolution
8
Flash & Validate

Flash the new interval values to the ECU. Re-run the 60-second test at 3 different setpoints (recommended: 30,000 · 10,000 · 1,000) and confirm detection within the expected window (±10%).

6. Post-Flash Validation Checklist

After flashing the new calibration, complete the following checks before sign-off:

  • Tyre inflated to target vehicle recommended pressure — verified with calibrated gauge
  • ECU flashed with new interval values — confirmed via readback on diagnostic tool
  • 60-second leak test at 30,000 leak rate setpoint — alert triggered within expected window (±10%)
  • 60-second leak test at 10,000 leak rate setpoint — alert triggered within expected window (±10%)
  • 60-second leak test at 1,000 leak rate setpoint — alert triggered within expected window (±10%)
  • No spurious alerts observed at rest (no orifice) over 5-minute observation period
  • Calibration data archived to Sightline project database with vehicle VIN and tyre batch number
🚫
Fail Criteria If any setpoint detection deviates by more than ±15% from expected, repeat the 60-second measurement (Steps 3–5) and recalculate. If deviation persists, escalate to the TPMS System Engineer.
